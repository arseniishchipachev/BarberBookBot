# Barber Book Bot 

Telegram-бот для автоматизации записи клиентов в барбершоп.

## Стек технологий
* Python 3.12

## Запланированный функционал
* Пошаговая запись пользователя через FSM (выбор услуги, мастера, даты и времени).
* Хранение информации о записях и мастерах в базе данных.
* Интеграция с Google Calendar API для синхронизации расписания мастеров.
