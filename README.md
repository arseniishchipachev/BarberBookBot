# 💈 BarberBookBot

Telegram-бот для автоматизации онлайн-записи клиентов в барбершоп. Написан на Python с использованием асинхронного фреймворка **Aiogram 3** и паттерна репозиториев (Repository Pattern).

## 🚀 Текущий функционал (MVP)
- **Каталог услуг**: фильтрация и просмотр услуг по категориям (Волосы, Борода, Комплексы).
- **Машина состояний (FSM)**: пошаговый сценарий бронирования:
  1. Выбор категории
  2. Выбор конкретной услуги из каталога
  3. Выбор доступного мастера
  4. Экран подтверждения с итоговым чеком
- **Информационный блок**: контакты барбершопа, адрес, график работы.
- **Архитектура**: разделение данных на DTO-модели и слой репозиториев (Mock/Fake Repository на этапе разработки).

## 🛠 Стек технологий
- Python 3.11+
- Aiogram 3.13.1
- Pydantic v2
- FSM (Finite State Machine)

## 📦 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone [https://github.com/ВАШ_НИК/BarberBookBot.git](https://github.com/ВАШ_НИК/BarberBookBot.git)
cd BarberBookBot
```
2. Создайте и активируйте виртуальное окружение:
```Bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```
3. Установите зависимости:
```bash
pip install -r requirements.txt
```
4. Создайте файл .env в корне проекта и укажите токен бота:
```Python
BOT_TOKEN=ваш_токен_от_BotFather
```
5. Запустите бота
