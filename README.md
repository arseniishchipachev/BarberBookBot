# 💈 BarberBookBot

Асинхронный Telegram-бот для автоматизации онлайн-записи клиентов в барбершоп с динамическим учетом занятых слотов и управлением визитами. Написан на Python с использованием фреймворка **Aiogram 3** и паттерна репозиториев (Repository Pattern).

## 🚀 Текущий функционал
- **Каталог услуг**: фильтрация и просмотр услуг по категориям (Волосы, Борода, Комплексы)[cite: 3].
- **Два сценария записи (FSM)**:
  - *От услуги:* Категория $\rightarrow$ Услуга $\rightarrow$ Барбер $\rightarrow$ Дата $\rightarrow$ Время $\rightarrow$ Подтверждение.
  - *От мастера:* Команда барберов $\rightarrow$ Профиль мастера $\rightarrow$ Категория $\rightarrow$ Услуга $\rightarrow$ Дата $\rightarrow$ Время $\rightarrow$ Подтверждение.
- **Интерактивный календарь**: выбор даты с постраничной пагинацией (листание периодов вперед и назад).
- **Динамические тайм-слоты**: автоматический расчет свободных часов мастера с фильтрацией уже занятого времени на стороне базы данных (`Appointment`).
- **Личный кабинет («Мои записи»)**: просмотр актуальных бронирований и моментальная отмена визита в один клик с валидацией владельца записи[cite: 2, 4].
- **Информационный блок**: просмотр карточек мастеров, контакты барбершопа, адрес и график работы[cite: 2, 4].
- **Архитектура**: чистая слоистая структура с разделением на ORM-модели, DTO, middleware сессий и слой репозиториев (Repository Pattern)[cite: 2, 4].

## 🛠 Стек технологий
- **Python 3.12**
- **Aiogram 3.x** (FSM, Routers, Middlewares, Inline/Reply Keyboards)
- **PostgreSQL** (реляционная СУБД)
- **SQLAlchemy 2.0 (Async)** (асинхронная ORM)
- **asyncpg** (высокопроизводительный асинхронный драйвер PostgreSQL)
- **Pydantic v2** (валидация данных и DTO)

## 📦 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone [https://github.com/arseniishchipachev/BarberBookBot.git](https://github.com/ВАШ_НИК/BarberBookBot.git)
cd BarberBookBot 
```
2. Создайте и активируйте виртуальное окружение:
python -m venv .venv

Windows:
```
.venv\Scripts\activate
```
Linux/macOS:
```
source .venv/bin/activate
```
3. Установите зависимости:
```
pip install -r requirements.txt
```
4. Создайте файл .env в корне проекта и укажите переменные окружения:
```
BOT_TOKEN=ваш_токен_от_BotFather
DB_URL=postgresql+asyncpg://postgres:password@localhost:5432/barberbook_db
```
5. Примените миграции / инициализируйте базу данных и запустите бота:
```aiignore
python main.py
```
